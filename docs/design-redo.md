# Personal homepage redo — decision record

## Brief, before drawing candidates

Audience: people arriving from Tony's projects, professional/community work and writing. Introduce Tony as a person with systems-engineering practice AND independent interests. Help visitors find a project to explore, learn about his background, or connect. This is not a new consultancy or a single-product landing page.

Baseline to beat: `846987908733abafe988369003dab32b113d8606`. Rejected redesign: `affe497e55bf4fb6be89c6a85e7864cd9de0b1cd` / PR #37. The shared main workflow used for this redo is Second Brain revision `98440d88bef426a4b2ff5151c937758678da5b26`; generic skills remain outside this repository.

Preserve: dominant Tony Wu identity, warm dark opening, illustrated multi-interest workspace, history/learning breadth, project image enlargement, prototype/qualification labels, author/source credits, existing public facts and destinations. Change: slow project scanning, small supporting text, generic new slogans and the engineering-only first impression of #37. Avoid: complete microscopic application screenshot as hero, unannounced employer changes, private family/client/financial details, or test counts presented as design success.

Criteria established BEFORE selection:
1. Tony's name remains the largest identity text; it is not replaced by a proposition.
2. Engineering, history and learning are visible as parts of one person's interests, not hidden under a consultancy pitch.
3. At 375x900, the opening has a useful action and recognizable storytelling imagery; credentials/abstract copy must not consume the first screen.
4. The first project region presents identifiable work and a direct destination without requiring a visitor to interpret tiny app controls.
5. Preserve qualifications, attribution, keyboard access, responsive behavior and real destinations.

## Pre-selection experiment

`tests/fixtures/design-directions.html` renders the same short biography, illustration, actions and three project entries in two compositions: A, name-led illustrated studio; B, image-led cover with an overlaid name and introduction below. Tests capture both at 1440x900 and 375x900, including first project region and complete slice. These are static layout studies, not evidence of working application behavior. Selection is deliberately not recorded until their actual captures are inspected.
